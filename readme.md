# Programação para Dispositivos Móveis

Repositório para o armazenamento de **atividades, exercícios e projetos desenvolvidos durante a disciplina de Programação para Dispositivos Móveis**.


---

## Sobre a disciplina

A disciplina aborda conceitos e práticas relacionados ao desenvolvimento de aplicações para dispositivos móveis, explorando ferramentas, linguagens, frameworks e boas práticas de desenvolvimento.

>  **Curso:** Desenvolvimento de Software Multiplataforma  
>  **Instituição:** FATEC Itaquera  
>  **Disciplina:** Programação para Dispositivos Móveis

---

## Tecnologias

As tecnologias utilizadas podem variar de acordo com cada atividade ou projeto.

Entre elas:

-  Desenvolvimento mobile
-  Linguagens de programação abordadas na disciplina
-  Frameworks e SDKs
-  Bancos de dados
-  APIs e serviços externos
-  Ferramentas de desenvolvimento

---

## Objetivo

Este repositório tem como objetivo:

- Organizar as atividades desenvolvidas durante a matéria;
- Centralizar os projetos e exercícios feitos;
- Acompanhar minha evolução no desenvolvimento mobile;
- Facilitar a entrega das atividades;
- Servir como histórico dos projetos desenvolvidos ao longo do semestre.
